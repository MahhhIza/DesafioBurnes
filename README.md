## Sobre a atividade

A atividade teve como objetivo implementar um sistema de cadastro e gerenciamento de banners, permitindo que as imagens cadastradas sejam exibidas na página inicial do projeto.

## Alterações realizadas

Durante o desenvolvimento, foram realizadas as seguintes etapas:

- Criação da tabela `banner` no banco de dados;
- Inclusão da opção **Banner** no menu administrativo;
- Criação do cadastro de banners;
- Implementação do upload das imagens;
- Implementação da listagem dos banners cadastrados;
- Implementação da edição dos registros;
- Implementação da exclusão dos banners;
- Criação de um Carousel utilizando Bootstrap na página inicial;
- Integração do Carousel com o banco de dados;
- Configuração para exibir somente os banners marcados como ativos.

## Funcionamento

O administrador pode cadastrar, editar e excluir banners pelo painel administrativo, além de definir se cada banner estará ativo ou não.

Na página inicial, os banners ativos são carregados diretamente do banco de dados e apresentados de forma automática por meio do Carousel do Bootstrap.

## Considerações finais

A implementação foi realizada mantendo a estrutura original do projeto e acrescentando as funcionalidades solicitadas na atividade.
